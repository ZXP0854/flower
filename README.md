# 浮光花事 - 花卉图鉴网站

一个基于 Web 的花卉图鉴和电商平台，展示中国各省特色花卉。

## 功能特点

### 🎨 核心功能
- **中国地图可视化**：使用 D3.js 绘制交互式中国地图，展示各省特色花卉
- **花卉图鉴**：展示精选花卉的详细信息，包括学名、描述等
- **花卉文化**：介绍花语起源、四季花卉、花卉艺术等文化内容
- **用户系统**：支持用户注册、登录、个人中心管理

### 🛒 电商功能
- **商品展示**：花卉相关用品展示（花盆、工具、肥料等）
- **购物车**：添加商品、数量管理、结算功能
- **商品筛选**：按分类筛选商品

### 🎯 用户体验
- **响应式设计**：适配各种屏幕尺寸
- **主题切换**：支持明暗主题切换
- **交互效果**：鼠标悬停、点击反馈等动画效果
- **省份交互**：点击地图省份查看当地特色花卉

## 技术栈

- **前端**：HTML5, CSS3, JavaScript
- **可视化库**：[D3.js v7](https://github.com/d3/d3) - 用于中国地图可视化
- **UI参考**：[Inspira UI](https://github.com/unovue/inspira-ui) - 界面设计参考
- **数据格式**：GeoJSON
- **存储**：LocalStorage（用户信息、购物车）
- **服务器**：Node.js（提供静态文件服务）

### 扩展技术说明

#### 1. D3.js 地图可视化
- **来源**：https://github.com/d3/d3
- **使用文件**：`d3-map.js`
- **功能**：
  - 使用 `d3.geoMercator()` 创建墨卡托投影
  - 使用 `d3.geoPath()` 生成地理路径
  - 加载 `china.json` GeoJSON 数据绘制真实省份轮廓
  - 支持鼠标悬停高亮和点击交互

#### 2. Inspira UI 设计参考
- **来源**：https://github.com/unovue/inspira-ui
- **使用文件**：`style.css`
- **功能**：
  - 响应式布局设计
  - 渐变色彩方案
  - 卡片阴影效果
  - 平滑过渡动画

## 地图功能

地图使用 D3.js 的墨卡托投影 (Mercator Projection)，从 `china.json` 加载真实的省份边界数据。

### 功能：
- ✅ 鼠标悬停高亮
- ✅ 点击查看省份花卉信息
- ✅ 省份名称标签
- ✅ 真实犬牙交错的省份轮廓

### 数据：
- 包含中国 34 个省级行政区
- 包含各省省会中心点坐标
- 详细的省份边界坐标点

##花卉数据

- **云南**：云南山茶

- **河南**：腊梅
